# 📚 Library Management System

![Library Management System Banner](./src/assets/images/book1.jpg)

## 🚀 Project Overview

The **Library Management System** is a modern web application designed for colleges and educational institutions. It helps students, employees, and administrators efficiently manage library operations through dedicated portals.

This project includes:

* 👨‍🎓 Student/User Portal
* 👩‍💼 Employee Portal
* 🛠️ Admin Portal
* 📖 Book Management
* ➕ Add Books
* ✏️ Update Books
* ❌ Delete Books
* 🔍 View Available Books
* 🎨 Responsive Modern UI

# Install dependencies
npm install

# Start development server
npm run dev
